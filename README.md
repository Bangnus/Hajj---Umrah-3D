# umrah-sim-th — จำลองอุมเราะฮ์และฮัจญ์ 3 มิติ

เครื่องจำลองสำหรับฝึกพิธีอุมเราะฮ์และฮัจญ์แบบ 3 มิติ รองรับทั้งภาษาไทยและภาษาอังกฤษ เล่นบนเบราว์เซอร์ได้ทั้งคอมพิวเตอร์ แท็บเล็ต และมือถือ
สร้างด้วย **TypeScript + Vite 6 + Three.js r170** ไม่ใช้ UI framework หรือ CSS framework ภายนอก (Vanilla DOM + CSS Variables ล้วน) และไม่พึ่งไฟล์โมเดล รูปภาพ หรือไฟล์เสียงภายนอก — ทุกฉาก ใบประกาศ และเสียงประกอบสร้างแบบ procedural บนเบราว์เซอร์

## ขอบเขตปัจจุบัน

### 1. โหมดอุมเราะฮ์ (9 ขั้นตอน)

เลือกเส้นทางได้ 2 แบบในหน้าเริ่มต้น:
- **มีกอตก่อน (`miqat-first`):** เตรียมตัว → สนามบิน → มีกอตบนเครื่องบิน → เฏาะวาฟ → ละหมาด + ซัมซัม → สะแอ → ตะฮัลลุล → ซิยาเราะฮ์มะดีนะฮ์ → เดินทางกลับบ้าน
- **มะดีนะฮ์ก่อน (`madinah-first`):** เตรียมตัว → สนามบิน → ซิยาเราะฮ์มะดีนะฮ์ → มีกอตบิอ์รอะลี → เฏาะวาฟ → ละหมาด + ซัมซัม → สะแอ → ตะฮัลลุล → เดินทางกลับบ้าน

| `id` | ขั้นตอน | สิ่งที่ผู้เล่นทำ |
|------|---------|----------------|
| `preparation` | เตรียมตัวที่บ้าน (บ้านไทย) | เก็บของจำเป็น 5 ชิ้น (ต่างกันตามเพศ) แล้วเดินออกจากบ้าน |
| `airport` | สนามบินสุวรรณภูมิ | เช็กอิน → ตรวจคนเข้าเมือง → ตรวจความปลอดภัย → ประตูขึ้นเครื่อง 14 |
| `miqat` | มีกอตบนเครื่องบิน *(เส้นทางมีกอตก่อน)* | เปลี่ยนชุดอิห์รอมท้ายเครื่อง กล่าวเนียตอุมเราะฮ์ และกล่าวตัลบิยะฮ์ |
| `miqatBirAli` | มีกอตบิอ์รอะลี *(เส้นทางมะดีนะฮ์ก่อน)* | เข้าซุ้มมีกอตซุลหุลัยฟะฮ์ อาบน้ำ/ครองอิห์รอม (ละหมาดซุนนะฮ์อิห์รอมได้) แล้วเนียตอุมเราะฮ์ |
| `tawaf` | เฏาะวาฟ | เริ่มที่แนวหินดำ เดินทวนเข็มนาฬิกา 7 รอบ (ผู้ชายแสดงอิฎฏิบาอ์เปิดไหล่ขวา) เตือนเมื่อเดินผิดทาง |
| `prayerZamzam` | ละหมาด 2 ร็อกอะฮ์ + ดื่มซัมซัม | ละหมาดหลังมะกอมอิบรอฮีมทีละท่า (`PRAYER_BEATS`) แล้วดื่มน้ำซัมซัม 3 อึก |
| `sai` | สะแอ | เริ่มที่เนินเศาะฟา เดินไป-กลับเศาะฟา–มัรวะฮ์ 7 เที่ยว ช่วงไฟเขียวผู้ชายวิ่งเหยาะ (ความเร็ว ×1.5) |
| `tahalul` | ตะฮัลลุล | ผู้ชายโกนศีรษะ / ผู้หญิงตัดปลายผม แล้วออกจากอิห์รอม |
| `madinah` | ซิยาเราะฮ์มะดีนะฮ์ | เข้ามัสยิดนะบะวี → ละหมาดที่อัรเราเฎาะฮ์ → ให้สลามแด่ท่านนบี ﷺ → สุสานอัลบะเกียะอ์ (พร้อมรถบัสเสริมไปมัสยิดกุบาอ์และภูเขาอุฮุด) |
| `returnHome` | เดินทางกลับบ้าน | อำลามัสยิดอัลฮะรอมหรือมัสยิดนะบะวี → ขึ้นเครื่องกลับ → เดินเข้าบ้านที่ประเทศไทย |

### 2. โหมดฮัจญ์ (9 ขั้นตอน)

รองรับฮัจญ์ทั้ง 3 ประเภท (**ตะมัตตุอ์** `tamattu`, **อิฟรอด** `ifrad`, **กิรอน** `qiran`) โดยฉากเริ่ม คำกล่าวเนียต จำนวนภารกิจ (การเชือดฮัดย์/ดัม) และคำอธิบายปรับตามประเภทฮัจญ์และเพศโดยอัตโนมัติ พร้อมระบบแสงตามเวลาจริง (`timeOfDay` / `skyClock` ตั้งแต่รุ่งสาง เที่ยง พลบค่ำ จนถึงกลางคืนมีดวงดาว):

| # | `id` | ขั้นตอน | สิ่งที่ผู้เล่นทำ |
|---|------|---------|----------------|
| 1 | `hajjIhram` | ครองอิห์รอมฮัจญ์ | **ตะมัตตุอ์:** อาบน้ำและครองอิห์รอมใหม่ที่โรงแรมในมักกะฮ์ (วันที่ 8) · **อิฟรอด / กิรอน:** ครองอิห์รอมและเนียตบนเครื่องบินก่อนผ่านมีกอต |

| 3 | `hajjArafah` | วุกูฟที่อะรอฟะฮ์ | เข้าเขตอะรอฟะฮ์ตามป้าย ละหมาดซุฮ์ริ+อัศริรวมและย่อ วุกูฟขอดุอาอ์จนดวงอาทิตย์ตก แล้วออกมุ่งหน้าสู่มุซดะลิฟะฮ์ |
| 4 | `hajjMuzdalifah` | ค้างคืนที่มุซดะลิฟะฮ์ | ละหมาดมัฆริบ+อิชาอ์รวมกัน เก็บก้อนหิน 7 ก้อน พักค้างคืน ละหมาดศุบฮิ และซิกร์ที่อัลมัชอะริลฮะรอมจนฟ้าสว่าง |
| 5 | `hajjAqabah` | ขว้างญัมเราะฮ์อะกอบะฮ์ | วันที่ 10 ขว้างเสาหินอะกอบะฮ์ 7 ก้อน → เชือดฮัดย์/ดัม *(เฉพาะตะมัตตุอ์และกิรอน)* → โกนศีรษะ (ชาย) / ตัดปลายผม (หญิง) ตะฮัลลุลขั้นแรก |
| 6 | `hajjIfadhah` | เฏาะวาฟอิฟาเฎาะฮ์ | เดินรอบกะอ์บะฮ์ 7 รอบในชุดปกติหลังตะฮัลลุลขั้นแรก |
| 7 | `hajjSai` | สะแอของฮัจญ์ | เดินสะแอเศาะฟา–มัรวะฮ์ 7 เที่ยว (ตะฮัลลุลขั้นที่สอง ข้อห้ามสิ้นสุดทั้งหมด) |
| 8 | `hajjTasyriq` | วันตัชรีก: ขว้างเสาหิน 3 ต้น | วันที่ 11–12 ขว้างศุฆรอ → วุสฏอ → อะกอบะฮ์ (แวะขอดุอาอ์หลังสองต้นแรก) ค้างคืนที่มีนา และเลือกออกวันที่ 12 ก่อนตะวันตก (นะฟัรเอาวัล) หรืออยู่ต่อวันที่ 13 (นะฟัรษานี) |

### 3. ความสามารถอื่น

- **รองรับ 2 ภาษา (ไทย / English):** สลับภาษาได้จากหน้าเริ่มและหน้าตั้งค่า (`umrahsim:lang`) แปลครบทั้ง UI ภารกิจ ป้ายในฉาก 3 มิติ เนื้อหาดุอาอ์ เสียงอ่าน และใบประกาศ
- **ตัวละครชายและหญิง:** เปลี่ยนชุดเดินทาง / ผ้าอิห์รอม / ฮิญาบ การเปิดไหล่ขวา (อิฎฏิบาอ์) ทรงผมหลังโกนหรือตัดปลายผม ท่าละหมาด ท่าขว้างเสาหิน และคำแนะนำเฉพาะเพศ
- **การ์ดดุอาอ์และซิกร์:** ดึงจาก `src/content/duas-th.json` แสดงตัวบทอาหรับ คำอ่าน ความหมาย ที่มา ระดับหะดีษ พร้อมปุ่ม `🔊` อ่านออกเสียงทีละส่วน
- **เสียงบรรยายและเสียงประกอบ:** บรรยายด้วย Web Speech API (ไทย / อังกฤษ / อาหรับ ปรับความเร็วช้า/ปกติ) และเสียงประกอบสังเคราะห์ด้วย WebAudio API โดยไม่ต้องโหลดไฟล์เสียง
- **ใบประกาศนียบัตรการฝึกพิธี:** วาดลง Canvas ขนาด `1600×1130` พร้อมกรอบลายเรขาคณิตอิสลาม แก้ไขชื่อได้ แสดงขั้นตอนที่ผ่านและวันที่ พ.ศ./ค.ศ. คู่กับฮิจเราะฮ์ศักราช ดาวน์โหลดเป็นไฟล์ PNG หรือแชร์ผ่าน Web Share API
- **บันทึกความคืบหน้าและตั้งค่า:** เก็บใน `localStorage` (`umrahsim:progress:v1`, `umrahsim:settings:v1`) กลับมาฝึกต่อจากขั้นตอนเดิมได้
- **รองรับจอมือถือเต็มรูปแบบ:** แผงภารกิจปรับเป็น bottom sheet ย่อ/ขยายได้ จอยสติ๊กสัมผัสซ้ายล่าง ปุ่มวิ่ง และลดจำนวนฝูงชน/เงาอัตโนมัติ (`Quality: 'low'`) บนอุปกรณ์จอสัมผัสหรือจอแคบกว่า `768px`

## เทคโนโลยีที่ใช้

| ส่วน | เทคโนโลยี |
|------|-----------|
| ภาษาและตัวรวมโมดูล | **TypeScript 5.7** + **Vite 6** (`es2022` + Dynamic Code-Splitting) |
| กราฟิก 3 มิติ | **Three.js r170** (Procedural Mesh + `InstancedMesh` + `CanvasTexture`) |
| ส่วนติดต่อผู้ใช้ (UI) | **Vanilla DOM + CSS Variables** (`src/ui/hud.ts`, `src/ui/styles.css`) ไม่ใช้ React/Vue/Tailwind |
| เสียง | **Web Speech API** (TTS) + **WebAudio API** (Synthesised SFX) |
| ใบประกาศ | **HTML5 2D Canvas** (`src/ui/certificate.ts`) |
| แคชและออฟไลน์ (PWA) | **vite-plugin-pwa (Workbox Service Worker)** แคชไฟล์และฟอนต์ลงเครื่อง รองรับผู้เล่นพร้อมกันจำนวนมากและเล่นออฟไลน์ได้ |

## การรันโปรเจกต์

```bash
npm install
npm run dev        # รันเซิร์ฟเวอร์พัฒนา http://localhost:5180
npm run typecheck  # ตรวจชนิดข้อมูล tsc --noEmit
npm run build      # typecheck + vite build → dist/
npm run preview    # ดูผล build ที่ http://localhost:5181
```

| การกระทำ | คีย์บอร์ด / เมาส์ | จอสัมผัส |

| ซูม | ล้อเมาส์ | — |
| ทำภารกิจ | เดินเข้าวงแหวนบนพื้น / กดปุ่มในแผงภารกิจ | เหมือนกัน |

ลูกศรสีเหลืองที่เท้าผู้เล่นชี้ไปยังเป้าหมายถัดไปโดยอัตโนมัติ

## การเพิ่มขั้นตอนใหม่และการแปลภาษา

1. สร้างไฟล์นิยาม `StageDef` ใน `src/journey/stages/umrah/` หรือ `src/journey/stages/hajj/` แล้วนำไปลงทะเบียนใน `src/journey/stages/registry.ts` (หรือ `hajj/index.ts`)
2. ข้อความภาษาไทยที่แสดงต่อผู้ใช้ทุกจุดให้ครอบด้วย `tr('ข้อความภาษาไทย')` หรือใช้ตัวแปรแทนค่า `tr('ครบรอบที่ {n}', { n })`
3. เพิ่มคำแปลภาษาอังกฤษโดยใช้ข้อความภาษาไทยเป็น key ในไฟล์พจนานุกรมภายใต้ `src/i18n/en/` (หากยังไม่ได้เพิ่ม คำนั้นจะแสดงภาษาไทยตามปกติโดยไม่ทำให้แอปพัง และตรวจสอบคำที่ตกหล่นได้จาก `missingTranslations()`)

helper หลักใน `StageCtx`:
- `ctx.add(scene)` — เพิ่มฉาก `Scene3D` (`group`, `colliders`, `tick`)
- `ctx.rings.add(x, z, r, onEnter, { label, color, persistent })` — วงแหวนภารกิจบนพื้น
- `ctx.progress(n = 1)` — เพิ่มตัวนับภารกิจ เมื่อครบ `mission.total` ปุ่ม "ไปต่อ" จะเปิดใช้งาน
- `ctx.dua(id)` — เปิดการ์ดดุอาอ์จาก `src/content/duas-th.json`
- `ctx.toast(msg, 'ok' | 'warn' | 'info')`, `ctx.hint(text)` — ข้อความแจ้งเตือนและคำใบ้
- `ctx.action(label, onClick)` — สร้างปุ่มกดในแผงภารกิจ (`setEnabled`, `setLabel`, `remove`)
- `ctx.guide({ x, z } | null)` — กำหนดเป้าหมายลูกศรนำทาง (`null` = ชี้ไปยังวงแหวนที่ใกล้ที่สุด)
- `ctx.after(seconds, fn)` — ตั้งเวลาที่จะถูกยกเลิกอัตโนมัติเมื่อเปลี่ยนขั้นตอน
- `ctx.timeOfDay(t)` — ปรับแสงท้องฟ้าตามเวลา (`0` รุ่งสาง, `0.5` เที่ยง, `1` พลบค่ำ, `1.25+` กลางคืน, `null` ค่าเริ่มต้น)
